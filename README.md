# javascript-calculator-precourse

## ✨ 구현할 기능 목록

### 1. 입력값을 문자열로 입력받는 기능
- 사용자가 입력한 값을 문자열로 받는다.

---

### 2. 기본 구분자(쉼표, 콜론)를 기준으로 문자열 분리 기능
- 입력된 문자열을 쉼표(`,`) 또는 콜론(`:`)을 기준으로 분리한다.

---

### 3. 커스텀 구분자 처리 기능
- `"//"`와 `"\n"` 사이에 위치한 문자를 커스텀 구분자로 추출한다.  
- 추출된 구분자를 사용해 문자열을 분리한다.

---

### 4. 분리된 문자열을 숫자로 변환하는 기능
- 문자열 리스트를 순회하며 정수로 변환한다.  
- 숫자가 아닌 값이 포함된 경우 예외를 발생시킨다.

---

### 5. 모든 숫자의 합을 계산하여 반환하는 기능
- 변환된 모든 숫자의 합을 계산하고 결과를 반환한다.

---

### 6. 잘못된 입력에 대한 에러 처리 기능
- 구분자 형식 오류, 숫자 변환 오류 등 잘못된 입력이 있을 경우 예외를 발생시킨다.
- 음수가 포함된 경우 다음 메시지와 함께 예외를 발생시킨다.


### 7. 결과 출력 및 빈 문자열 처리 기능
- 계산 결과를 콘솔로 출력한다.  
- 입력값이 빈 문자열(`""`)인 경우 0을 반환하고 출력한다.
